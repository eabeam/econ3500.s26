Testing Hypotheses About \(\beta_1\)

The Challenge: Sampling Uncertainty

Recall from Chapter 4:

  • We estimated \(\hat\beta_1 = 0.80\) (effect of height on income)
  • But this is just one sample from the population
  • If we drew a different sample, we’d get a different \(\hat\beta_1\)
  • Question: How confident can we be that the true \(\beta_1 \neq 0\)?

The Core Problem

\(\hat\beta_1\) is a random variable with its own sampling distribution.
We need a framework to separate signal from noise.

Sampling Distribution of \(\hat\beta_1\) (Review)

Under the least squares assumptions, for large \(n\):

\[ \hat\beta_1 \sim N\left(\beta_1,\ \frac{\sigma^2_v}{n \cdot \operatorname{Var}(X)}\right), \]

where \(v_i = (X_i - \mu_X)u_i\).

Key insight:

  • \(\hat\beta_1\) is centered at the true \(\beta_1\) (unbiased)
  • The spread (variance) depends on sample size \(n\), variation in \(X\), and error variance
  • By the Central Limit Theorem, \(\hat\beta_1\) is approximately normal in large samples

Setting Up a Hypothesis Test

Null hypothesis \(H_0\): the claim we’re testing.
Alternative hypothesis \(H_1\): what we suspect if \(H_0\) is false.

Two-tailed test

\[ H_0: \beta_1 = \beta_{1,0} \quad \text{vs} \quad H_1: \beta_1 \neq \beta_{1,0}. \]

One-tailed tests

\[ H_0: \beta_1 = \beta_{1,0} \quad \text{vs} \quad H_1: \beta_1 > \beta_{1,0} \]

or

\[ H_0: \beta_1 = \beta_{1,0} \quad \text{vs} \quad H_1: \beta_1 < \beta_{1,0} \]

where \(\beta_{1,0}\) is the hypothesized value under the null (often 0).

The \(t\)-Statistic: Our Test Statistic

General formula for any hypothesis test

\[ t = \frac{\text{estimator} - \text{hypothesized value}}{\text{SE of estimator}}. \]

For testing \(H_0: \beta_1 = \beta_{1,0}\):

\[ t = \frac{\hat\beta_1 - \beta_{1,0}}{\operatorname{SE}(\hat\beta_1)}. \]

Interpretation

  • Measures how many standard errors \(\hat\beta_1\) is away from \(\beta_{1,0}\)
  • If \(|t|\) is large, \(\hat\beta_1\) is far from \(\beta_{1,0}\) \(\Rightarrow\) evidence against \(H_0\)
  • Under \(H_0\), \(t \sim N(0,1)\) in large samples

Decision Rule: When to Reject (H_0)

Rejection regions for one- and two-sided tests

Reject \(H_0\) at significance level \(\alpha\) if:

  • Two-tailed: \(|t| > c_{\alpha/2}\)
  • One-tailed (upper): \(t > c_{\alpha}\)
  • One-tailed (lower): \(t < -c_{\alpha}\)

One-Tailed vs Two-Tailed Tests

One- vs two-tailed tests

Which to use?

  • Two-tailed: Most common in economics (test for any effect)
  • One-tailed: When theory strongly predicts a direction

Critical Values for Common Significance Levels

Significance level \(\alpha\) Two-tailed \(c_{\alpha/2}\) One-tailed \(c_{\alpha}\)
10% 1.645 1.28
5% 1.96 1.645
1% 2.58 2.33

Rule of thumb: For two-tailed tests at 5%, reject if \(|t| > 2\).

Requirements:

  • Large sample (\(n > 30\) as a minimum for CLT to apply)
  • All three least squares assumptions hold

Knowledge Check: Calculate the \(t\)-Statistic

Question

You estimate \(\hat\beta_1 = 3.5\) with \(\operatorname{SE}(\hat\beta_1) = 1.2\).
Test \(H_0: \beta_1 = 0\) vs \(H_1: \beta_1 \neq 0\) at 5% level.

  1. What is the \(t\)-statistic?
  2. What is your decision?

Answer

  1. \(t = \dfrac{3.5 - 0}{1.2} = 2.92\)
  2. Since \(|2.92| > 1.96\), reject \(H_0\) at 5% level.
    Conclusion: strong evidence that \(\beta_1 \neq 0\).

Type I and Type II Errors

Type I and Type II errors

  • Type I error (\(\alpha\)): Reject \(H_0\) when it’s true (false positive)
  • Type II error (\(\beta\)): Fail to reject \(H_0\) when it’s false (false negative)
  • Power \((1-\beta)\): Probability of correctly rejecting false \(H_0\)

Choosing a Significance Level

Why (= 0.05) is conventional

  • We tolerate a 5% chance of false positives
  • Balances Type I and Type II errors
  • Widely accepted standard in social sciences

The tradeoff

  • Smaller () () fewer false positives, but more false negatives (lower power)
  • Larger () () more false positives, but fewer false negatives (higher power)
  • You cannot minimize both at once.

We typically fix () and try to increase power by increasing (n).

Statistical Power

Power curve

  • Larger true effect size (|_1|)
  • Larger sample size (n)
  • Smaller error variance (^2_u)

Critical distinction

95% Confidence Interval

A random interval that contains the true parameter 95% of the time in repeated samples.

Two equivalent interpretations:

The Link Between CIs and Hypothesis Tests

Key relationship

  • If (_{1,0}) is inside the 95% CI, we fail to reject (H_0: 1 = {1,0}) at 5% level.
  • If (_{1,0}) is outside the 95% CI, we reject (H_0: 1 = {1,0}) at 5% level.

Example

  • (H_0: _1 = 4) () 4 is in CI () fail to reject

Takeaway: CIs provide more information than hypothesis tests—they show a range of plausible values.

Regression When (X) is Binary

Binary Variables in Regression

Often, our regressor takes only two values:

  • (X = 1) if small class, (X = 0) if large class
  • (X = 1) if treated, (X = 0) if control
  • (X = 1) if college degree, (X = 0) if no degree
  • (X = 1) if female, (X = 0) if male

These are called binary variables, dummy variables, or indicator variables.

Terminology

  • (X = 1): “treatment group” or “category of interest”
  • (X = 0): “control group” or “reference category”

What Does (_1) Mean for Binary (X)?

Population regression model:

[ Y_i = _0 + _1 X_i + u_i. ]

When (X_i = 0) (control group):

[ Y_i = _0 + u_i, E[Y_i X_i = 0] = _0. ]

When (X_i = 1) (treatment group):

[ Y_i = _0 + _1 + u_i, E[Y_i X_i = 1] = _0 + _1. ]

Interpretation of (_1)

[ _1 = E[Y_i X_i = 1] - E[Y_i X_i = 0]. ]

(_1) is the difference in group means.

Visualizing Binary Regressors

Binary regressor visualization

  • (_0): mean of control group ((X = 0))
  • (_0 + _1): mean of treatment group ((X = 1))
  • (_1): vertical distance between group means

Binary Regressors and Randomized Experiments

Special case: when (X) is randomly assigned (like a clinical trial)

  • Zero conditional mean assumption automatically satisfied
  • (E[u X] = 0) because treatment is independent of all confounders
  • (_1) has a causal interpretation: the average treatment effect

Observational data (no randomization)

  • Must worry about confounders
  • E.g., college graduates might differ in unobservable ways (ability, motivation)
  • (_1) captures association, not necessarily causation

Takeaway: Randomization is the gold standard for causal inference.

Heteroskedasticity and Homoskedasticity

What is Heteroskedasticity?

Homoskedasticity

The variance of the error term is constant across all values of (X):

[ (u X = x) = ^2_u x. ]

Heteroskedasticity

The variance of the error term depends on (X):

[ (u X = x) x. ]

Pronunciation:

  • Homoskedasticity: “homo-sked-ASS-tiss-ity” (constant variance)
  • Heteroskedasticity: “hetero-sked-ASS-tiss-ity” (varying variance)

Visualizing Homoskedasticity vs Heteroskedasticity

Homoskedastic vs heteroskedastic residuals

  • Left panel (homoskedastic): residuals have same spread at all (X) values
  • Right panel (heteroskedastic): residuals fan out as (X) increases

Does Heteroskedasticity Affect (_1)?

Short answer: No.

Recall the three least squares assumptions:

  1. (E[u X] = 0) (zero conditional mean)
  2. ((X_i, Y_i)) are i.i.d.
  3. Large outliers are rare

Notice: we never assumed homoskedasticity. Our assumptions allow for heteroskedasticity.

  • (_1) is still unbiased and consistent
  • Point estimates are fine

So Why Care About Heteroskedasticity?

The problem: heteroskedasticity affects standard errors.

  • If errors are homoskedastic, the “textbook” SE formula is correct
  • If errors are heteroskedastic, that formula is wrong
  • Wrong SEs () wrong (t)-statistics () wrong (p)-values () wrong conclusions

The Solution

Use heteroskedasticity-robust standard errors (also called “robust SEs” or “Huber–White SEs”).
These are valid whether errors are homo- or heteroskedastic.

Robust Standard Errors in Stata

Default (homoskedastic SEs – not recommended)

With robust SEs (always do this)

regress wage education, robust

What changes:

  • Coefficient estimates: unchanged
  • Standard errors: typically change slightly
  • (t)-statistics and (p)-values: adjusted accordingly

Comparing Homoskedastic and Robust SEs

SE comparison

  • In this example with heteroskedasticity, robust SE is larger
  • But this isn’t always the case – it can go either way
  • Always use robust SEs as a precaution

Heteroskedasticity: The Bottom Line

Situation Homoskedastic SE Robust SE
Errors are homoskedastic Correct Correct
Errors are heteroskedastic Wrong Correct

Practical advice

Always use robust standard errors.
No downside if errors are homoskedastic, protects you if they’re not.

The Gauss–Markov Theorem

Historical Note: When is OLS “Optimal”?

Important context

This section presents a theoretical result that’s mathematically beautiful but has limited practical relevance in modern empirical work.

Why learn it anyway?

  • Appears in textbooks and older papers
  • Helps understand why OLS is the “default” estimator
  • Shows what assumptions make OLS theoretically optimal
  • But: we’ve already learned the practical solution (robust SEs)

When is OLS “Best”?

We know OLS is unbiased and consistent under the three LS assumptions.

But is it the best estimator we could use?

The Gauss–Markov theorem answers this under a fourth assumption.

Extended LS assumptions (four total):

  1. (E[u X] = 0)
  2. ((X_i, Y_i)) are i.i.d.
  3. Large outliers are rare
  4. (u) is homoskedastic

The Gauss–Markov Theorem

Gauss–Markov Theorem

Under the four extended least squares assumptions, (_1) has the smallest variance among all linear unbiased estimators.

This makes OLS BLUE:

  • Best (minimum variance)
  • Linear (estimator is a linear function of (Y_1, , Y_n))
  • Unbiased ((E[_1] = _1))
  • Estimator

What BLUE Means (and Doesn’t Mean)

BLUE means

  • Among all linear unbiased estimators, OLS is most precise (smallest ((_1)))
  • Under homoskedasticity, you can’t do better with a linear estimator

BLUE does not mean

  • OLS is best among all estimators (only linear ones)
  • OLS is best when errors are heteroskedastic (theorem requires homoskedasticity)
  • OLS is unbiased without the zero conditional mean assumption (still need assumption 1)

Limitations of the Gauss–Markov Theorem

Why we don’t rely heavily on it:

  1. Homoskedasticity is rare in practice
    • Real-world data almost always exhibit some heteroskedasticity
    • The theorem doesn’t apply
  2. Restricted to linear estimators
    • Many better nonlinear estimators exist
    • E.g., weighted least squares (if we know form of heteroskedasticity)
    • E.g., least absolute deviations (robust to outliers)

Takeaway: OLS is a good default, but not always optimal.

Gauss–Markov: The Practical Bottom Line

What you need to remember:

  • Gauss–Markov says OLS is BLUE under homoskedasticity
  • But homoskedasticity rarely holds in practice
  • Modern solution: use OLS with robust standard errors
    • Point estimates (_1): unchanged
    • Standard errors: corrected for heteroskedasticity
    • Inference: valid whether or not errors are homoskedastic

Practical advice

Don’t worry too much about whether errors are homoskedastic.
Just always use , robust in Stata.

Why We Still Use OLS

Despite limitations, OLS is the workhorse of econometrics:

  • Simplicity: easy to compute and interpret
  • Robustness: works reasonably well under a wide variety of conditions
  • Robust SEs: fix the heteroskedasticity problem for inference
  • Familiarity: everyone knows how to interpret regression output
  • Unbiased under weak assumptions: just need (E[u X] = 0), i.i.d., no huge outliers

Modern practice

Use OLS with robust standard errors as your baseline.
Consider alternatives (WLS, LAD, etc.) only when you have specific concerns.

Common Mistakes to Avoid

  1. Using homoskedastic SEs instead of robust
    • Always add , robust in Stata.
  2. Confusing statistical and economic significance
    • Check both the (p)-value and the magnitude.
  3. Misinterpreting confidence intervals
    • The interval is random, not the parameter.
    • “95% confident” () “95% probability”.
  4. Forgetting that binary regressors are differences in means
    • For a binary regressor, (_1) is a difference in group means.
  5. Thinking BLUE applies with heteroskedasticity
    • Gauss–Markov requires homoskedasticity.
