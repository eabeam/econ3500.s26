# CLAUDE.md — ECON3500 Econometrics & Applications (Spring 2026)

## Project Overview

Advanced econometrics course, Spring 2026 semester at UVM. Course website built with Hugo + Netlify (academic theme).

**Hub**: `~/Dropbox/Github/eb-lab/projects/econ3500/HUB.md`

## Repository Structure

This is a Hugo-based course website, not a data analysis project.

| Directory | Contents |
|---|---|
| `content/` | Course pages, assignments, problem sets |
| `assets/` | Static assets (images, custom CSS) |
| `config/` | Hugo configuration |
| `datasets/` | Course datasets for student use |
| `data/` | Hugo data files |
| `layouts/` | Hugo templates |
| `public/` | Built site output (gitignored) |

## Build & Deploy

- **Framework**: Hugo with academic theme
- **Deploy**: Netlify (see `netlify.toml`)
- **Local preview**: `hugo server`
- **Tool management**: `mise.toml` for version pinning

## Conventions

- Course materials on OneDrive (canonical), not in this repo
- Stata is the primary statistical software for the course
- This repo is the public-facing course website only
